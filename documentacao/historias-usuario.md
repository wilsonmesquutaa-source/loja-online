        Cliente / Visitante

# Como visitante,
quero visualizar os produtos disponíveis,
para conhecer os salgados oferecidos pela loja.

# Como visitante,
quero navegar pelas categorias de produtos,
para encontrar facilmente o tipo de salgado que desejo comprar.

# Como visitante,
quero adicionar produtos ao carrinho,
para selecionar os itens que pretendo comprar.

# Como cliente,
quero alterar a quantidade dos produtos no carrinho,
para ajustar meu pedido antes de finalizar a compra.

# Como cliente,
quero remover produtos do carrinho,
para corrigir escolhas feitas anteriormente.

# Como cliente,
quero finalizar uma compra sem cadastro,
para realizar meu pedido de forma rápida.

# Como cliente,
quero criar uma conta no sistema,
para salvar meus dados e facilitar compras futuras.

# Como cliente,
quero realizar login,
para acessar meus dados e histórico de pedidos.

# Como cliente,
quero escolher entre entrega e retirada no local,
para selecionar a forma mais conveniente de receber meu pedido.

# Como cliente,
quero escolher uma forma de pagamento,
para concluir minha compra da maneira desejada.

# Como cliente,
quero receber a confirmação do pedido pelo WhatsApp,
para saber que minha compra foi registrada.

# Como cliente,
quero acompanhar o status do pedido,
para saber em qual etapa ele está.

# Administrador
Como administrador,
quero cadastrar produtos,
para manter o catálogo da loja atualizado.

# Como administrador,
quero editar informações dos produtos,
para corrigir preços, descrições e disponibilidade.

# Como administrador,
quero cadastrar categorias,
para organizar melhor os produtos da loja.

# Como administrador,
quero visualizar pedidos recebidos,
para preparar e entregar as compras dos clientes.

# Como administrador,
quero alterar o status dos pedidos,
para informar ao cliente o andamento da compra.

# Como administrador,
quero gerenciar clientes cadastrados,
para manter os dados organizados.

# Como administrador,
quero controlar produtos em estoque,
para evitar vender itens indisponíveis.

# Como administrador,
quero visualizar relatórios de vendas,
para acompanhar o desempenho da loja.
