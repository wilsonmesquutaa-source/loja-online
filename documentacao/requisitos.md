# Requisitos funcionais

O sistema deverá permitir o cadastro de clientes.
O sistema deverá permitir login de clientes e administradores.
O sistema deverá permitir o gerenciamento de produtos (cadastrar, editar, visualizar e excluir).
O sistema deverá permitir o cadastro e gerenciamento de categorias de produtos.
O sistema deverá listar os produtos disponíveis para os clientes.
O sistema deverá permitir pesquisar produtos pelo nome ou categoria.
O sistema deverá permitir visualizar detalhes dos produtos.
O sistema deverá permitir adicionar produtos ao carrinho de compras.
O sistema deverá permitir alterar a quantidade dos itens no carrinho.
O sistema deverá permitir remover produtos do carrinho.
O sistema deverá calcular automaticamente o valor total do pedido.
O sistema deverá permitir cadastrar e gerenciar endereços de entrega dos clientes.
O sistema deverá permitir finalizar pedidos informando endereço e forma de pagamento.
O sistema deverá registrar os pedidos realizados pelos clientes.
O sistema deverá permitir acompanhar o status dos pedidos.
O sistema deverá permitir que administradores visualizem e gerenciem os pedidos recebidos.
O sistema deverá permitir alterar o status do pedido (aguardando, preparando, saiu para entrega e finalizado).
O sistema deverá armazenar o histórico de pedidos dos clientes.
O sistema deverá permitir o gerenciamento de usuários administrativos.
O sistema deverá permitir controlar produtos ativos e indisponíveis para venda.
O sistema deverá registrar informações de data e horário dos pedidos realizados.

# Requisitos não funcionais

A aplicação deverá funcionar em computadores, tablets e celulares.
O sistema deverá possuir interface responsiva e adaptável a diferentes tamanhos de tela.
A aplicação deverá utilizar PHP puro, MySQL, HTML5, CSS3 e JavaScript moderno.
As consultas ao banco de dados deverão utilizar prepared statements para evitar SQL Injection.
As senhas dos usuários deverão ser armazenadas utilizando métodos seguros de criptografia (hash).
O sistema deverá possuir controle de acesso para impedir usuários não autorizados.
Os dados enviados pelos formulários deverão ser validados no servidor.
O sistema deverá possuir mensagens de erro amigáveis sem expor informações sensíveis.
O banco de dados deverá possuir integridade através de chaves primárias e estrangeiras.
A aplicação deverá possuir código organizado seguindo boas práticas de desenvolvimento.
O sistema deverá permitir manutenção e expansão futura de novas funcionalidades.
O sistema deverá possuir carregamento eficiente das páginas para melhorar a experiência do usuário.
A aplicação publicada deverá utilizar conexão segura HTTPS.
O sistema deverá realizar backup periódico das informações do banco de dados.
